Jexlヘルプ Excel Search 用クイックリファレンス / @jbrowse/jexl 6.0.0

検索モードを「条件式 (Jexl)」にすると、Excelの各行に対してJexl式を評価します。検索欄は上部に固定されているので、ヘルプを表示したまま式を編集できます。

最小の例

表示列名で検索
cols["型式"] ~ "ZZ$"
Jexl式の結果が true なら一致します。現行の検索では、Boolean以外もJavaScriptのtruthy/falsyで判定します。期待と違う場合は右上の「⋯ → 検索の検証」で行ごとの評価値・型を確認してください。

cols / values 等はExcelの生値（数値・Boolean・文字列）です。例：cols["フラグ"] == true、cols["数量"] > 10。日付セルは共通1900方式のExcelシリアル値（数値）。書式付き表示値は texts["納期"] などの text* 変数で参照できます。列がない場合は undefined、空白セルは null です。

正規表現は cols["型式"] ~ "^ABC.*ZZ$" のように文字列で指定します。/^ABC/ の正規表現リテラルは使いません。パターン先頭の (?i) で大文字小文字を無視できます。

追加ANDフィルタは、通常・正規表現・Jexlのいずれかで指定でき、メイン検索結果をさらに絞ります。「Jexlへ統合」で現在の条件を1本の式へ変換できます。

Jexlとヘルプはローカル同梱されています。条件式検索もオフラインで利用できます。

各行の評価に渡される変数です。列の有効／無効、表示名、表示順はRead Unit（シート・テーブル・範囲）ごとの設定に従います。

式・変数意味

現在の検索対象で使われている表示列名

有効なRead Unitの列名をまとめて表示します。Read Unitによって存在する列は異なります。列名をクリックすると式を検索欄へ挿入します。

演算子

演算子意味・例
&& / || / !AND / OR / NOT。&& が || より優先されます。括弧で組み合わせられます。
== / !=等しい / 等しくない。
> / >= / < / <=大小比較。数値・日時シリアルは cols["数量"] > 10 のように直接比較できます。
in配列への所属、文字列の部分一致。例：cols.A in ["X", "Y"] / "ABC" in cols.B
~ / !~正規表現に一致 / 不一致。例：cols.B ~ "ZZ$"
??値がnull/undefinedのときだけ代替値を使用。例：cols.A ?? ""
条件 ? A : B条件演算子。どちらか一方の値を返します。
+ - * / %加減乗除・剰余。+ は文字列の連結にも使います。

リスト・関数

JBrowse版 Jexl 6には、ラムダ（v => 条件）とリスト関数が用意されています。

関数用途・例
any(xs, v => …)1件でも条件を満たす。any(textValues, v => "QQQQ" in v)
all(xs, v => …)すべての要素が条件を満たす。
count(xs, v => …)条件を満たす件数。
filter(xs, v => …)条件に合う要素を配列で取得。
map(xs, v => …)各要素を変換して配列にする。
find / sort / reduce最初の該当要素、並び替え、畳み込み。
min / max / sum / mean / median数値等を集計。文字列の数値化が必要な場合は型に注意。

複数式・一時計算列・一時表示ルール

Jexl 6 は ; で式を区切れます。最後の式の戻り値が検索条件になります。&& / || の短絡評価を避けたい表示操作は、独立した文として書いてください。

amount = cols["数量"] * cols["単価"];
calcColumn("金額", amount, {format: "#,##0"});
formatIf(amount >= 1000, {columns: ["金額"], background: "warning", icon: "star"});
amount >= 500
追加Jexl関数用途
calcColumn(name,value,opts?)検索中だけ計算列を追加。{format: "#,##0"} はExcel SSF書式。定義後は cols["金額"] などから利用可能。正常終了時は true。
formatIf(condition,opts)条件一致時に一時的な背景色・アイコン・罫線を付加。正常終了時は true。columns: ["状態"] や columns: ["*"]、background: "danger"、icon: "flag"、border: "top" を指定。
rowAt(offset,name)読み込み単位の元データ順で前後行の型付き値を取得。例：rowAt(-1,"品番")。
textAt(offset,name)元データ順で前後行の表示文字列を取得。
resultAt(offset,name)検索後の行順。永続表示ルール用（検索評価中は結果が未確定なので参照不可）。

更新とユーザー定義関数：「対象」から各Read Unitの「表示設定」を開き、計算列・条件付き書式・グループを登録できます。永続定義には「変更時のみ／起動時／定期」の再計算ポリシーがあります。右上の「⋯ → ユーザー定義関数」で、引数とJexl式を持つ関数を現在のワークスペース内で共通登録できます。

永続計算列は依存関係順に評価し、循環参照は禁止します。一時計算列は行ごとに同じ列を独立した文で定義してください。ユーザー定義関数内での calcColumn() / formatIf() は禁止です。計算列は物理列 excel.A には含みません。
Excel Search 独自関数 searchText(対象, "文字列", {caseSensitive: false}) と searchRegex(対象, "正規表現", {caseSensitive: true}) も使えます。対象は textValues・textIloc・texts・特定セルの値などを指定します。{column: "型式"} / {columns: ["型式", "品名"]} で列を限定できます。関数の一致セルは可能な範囲で強調表示されます。
values は生値配列で、textValues は表示文字列配列です。同名列は配列になります。文字列検索・正規表現には texts 等の使用を推奨します。~ の大文字小文字の指定には (?i) を使います。

型変換・日付／時刻（Excel Search独自関数）

関数使い方
string(x) / number(x) / boolean(x)明示的に型変換。解析不能な値は null。例: boolean("FALSE") == false
equals(a,b)型まで厳密に比較。例: equals(10, "10") → false
date(x) / parseDate(text, pattern)ISO日付または指定書式からExcelシリアル値へ変換。例: date("2026-10-19")、parseDate("19/10/2026", "DD/MM/YYYY")
formatDate(serial, pattern)共通書式で文字列化。例: formatDate(cols["納期"], "YYYY/MM/DD HH:mm")
today() / now()ローカルの本日（0時）／現在日時をシリアル値で取得。
time(text) / timeOf(serial)time("13:30") → 0.5625。timeOf() は日時の時刻部分を返します。
hour(x) / minute(x) / second(x)日時から時・分・秒を取得。
addDays(x,n) / addMonths(x,n)日付加算。月加算は月末補正。
addHours(x,n) / addMinutes(x,n) / addSeconds(x,n)時間単位で加算・減算。
daysBetween(a,b) / hoursBetween(a,b) / minutesBetween(a,b) / secondsBetween(a,b)日数／時間差（b−a）。
sameDay(a,b) / dateBetween(x,from,to)暦日一致／両端を含む日付範囲の判定。
startOfMonth(x) / endOfMonth(x)月初／月末の0時をシリアル値で返す。
書式は date-and-time 4.6.0 形式（YYYY=年、MM=月、DD=日、HH=時、mm=分、ss=秒）。Excelセルの表示書式と異なります。日付はタイムゾーンを持たない数値で、1900/1904方式を正規化します。Excelの架空の1900年2月29日（シリアル60）は日付変換できません。

変数代入（x = 5; x > 3）、テンプレート文字列（`ID: ${cols.A}`）にも対応します。Jexl v6では古いJexlのパイプ変換（|lower）は利用しません。

詳細な文法は @jbrowse/jexl 公式リファレンスを参照してください（外部サイト）。
